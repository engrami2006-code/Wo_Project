# Course Concept → Implementation Traceability

This is the traceability matrix required by `prompt/MASTER_PROMPT_v2.md` §2. Each row was checked against the
repository on 3 October 2026:

- **Code**: the path exists, and the named classes and functions are defined there.
- **Test**: the test that covers the concept in `backend/tests/` (88 tests) or `frontend/src/__tests__/` (17 tests).
  Where the file differs from the one the specification names, the specification's name is given in brackets.
- **UI**: the page or component where the concept is visible, with a screenshot from [`screenshots/`](screenshots/).
- **Docs**: the page that explains the concept, often with a real run.

Code paths are relative to `backend/app/`, UI paths to `frontend/src/` and test paths to `backend/tests/`. Test
results (88 passed on SQLite and on PostgreSQL) are in [testing.md §6](testing.md#6-results).
